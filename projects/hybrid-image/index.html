Hybrid Image Generation

An undergraduate image-processing project originally implemented in MATLAB. The two original project images are used below. Adjust the filters to see how low-frequency information from one image and high-frequency detail from the other combine into a hybrid image.

Method: Image A is blurred to retain low spatial frequencies. A blurred copy of Image B is subtracted from Image B to isolate high-frequency detail. The two components are then added together.
